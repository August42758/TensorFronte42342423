# Проект: Выбор даты и времени

## Описание задания
Выполнена вёрстка страницы «Выбор даты и времени» для пути записи клиента в салон красоты «ЛУНА». Работа выполнена по макету из Figma с использованием семантической HTML-разметки, Flexbox и CSS Grid. Стили вынесены в отдельный файл.

## Как открыть проект
1. Скачайте папку `frontend-1-practice`.
2. Откройте файл `index.html` двойным кликом мыши - страница откроется в браузере по умолчанию.
