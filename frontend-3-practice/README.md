# Задание 3. Основы React

Страница выбора даты и времени салона «ЛУНА» из `frontend-2-practice` переведена на React и Vite. Оформление и поведение сохранены.

## Как запустить

Нужен Node.js 20.19+ или 22.12+ (подойдут и более новые версии).

```sh
cd frontend-3-practice
npm install
npm run dev
```

Откройте адрес, который напишет Vite. HTML нельзя запускать двойным кликом: JSX обрабатывается сборщиком.

Сборка и просмотр готовой версии:

```sh
npm run build
npm run preview
```

## Реализация

- `src/main.jsx` — точка входа React и подключение CSS.
- `src/App.jsx` — состояние и обработчики. `currentMonth`, `currentYear`, `selectedDay`, `selectedTime`, `slots` хранятся в отдельных `useState`. Дополнительное состояние управляет окном подтверждения.
- `src/components/` — отдельные компоненты шапки, индикатора шага, заголовка календаря, сетки, слотов, нижней панели, подтверждения и подвала. Данные и обработчики передаются через пропсы.
- `src/data/date.js` — чистые функции календаря и сравнения дат, массивы названий дней и месяцев. Месяцы имеют индекс 0–11, неделя начинается с понедельника.
- `src/data/slots.js` — три учебных расписания и функция выбора слотов для даты.
- `src/index.css` — сброс и контейнер React; `src/styles.css` — стили прошлой практики.

Календарь и слоты рендерятся через JSX и `.map()` со стабильными `key`. Обработчики назначены через `onClick` и замыкания; ручная сборка HTML и `addEventListener` не используются. `useRef` и `useEffect` нужны только для прокрутки и нативного модального `dialog`.

Сегодня определяется по локальной дате браузера. При открытии выбран сегодняшний день и видны его слоты. Прошедшие дни и ячейки соседнего месяца недоступны. Просмотр другого месяца сохраняет выбранную дату; выбор другого дня обновляет расписание и сбрасывает время. «Далее» открывает учебное подтверждение, без отправки записи в салон.

## Три сценария для проверки

1. Откройте страницу: сегодня выделено, шесть слотов отображаются. Выберите время: слот подсвечен, нижняя панель содержит день недели, число, месяц, год и время. «Далее» открывает подтверждение; его можно закрыть кнопкой или Escape и открыть повторно.
2. Выберите другой день: расписание меняется, выбранное время сбрасывается, «Далее» отключена до нового выбора времени.
3. Перелистайте месяцы вперед и назад, включая переход декабрь–январь. Выберите будущий день после переключения. Перейдите в прошлый месяц: дни приглушены и не кликаются.

Исходные папки прошлых практик сохранены. Примеры `frontend-3-lesson` и `frontend-3-complete` в проекте отсутствуют; React-компоненты написаны под собственную верстку.
