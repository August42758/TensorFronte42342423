# Практика 2: JavaScript — выбор даты и времени

Верстка салона «ЛУНА» перенесена из `frontend-1-practice` и оживлена на нативном JavaScript без фреймворков.

## Запуск

Откройте `index.html` в браузере. Сервер и установка зависимостей не нужны.

## Что работает

- При открытии выбран сегодняшний день, отображается его расписание.
- Стрелки переключают месяцы, включая переход между годами.
- Прошедшие дни приглушены и недоступны для выбора. Дни соседних месяцев также недоступны: для выбора переключите месяц.
- Выбор другой даты обновляет слоты и сбрасывает выбранное время.
- Выбор времени подсвечивает слот и обновляет нижнюю панель с днем недели, числом, месяцем и годом.
- «Далее» доступна после выбора времени и открывает подтверждение. Это учебный экран: данные не отправляются в салон.
- Кнопками можно пользоваться с клавиатуры; изменения выбора озвучиваются через `aria-live`.

## Файлы и устройство JavaScript

- `index.html` — исходная верстка, стрелки календаря, нижняя панель и окно подтверждения. `script.js` подключен в конце `body`.
- `styles.css` — стили прошлой практики и стили интерактивных состояний.
- `script.js` — данные, состояние, чистые функции, рендер, обработчики и `init()`, вызванная через `DOMContentLoaded`.

Сегодня определяется через `new Date()` по локальному времени браузера. Слоты берутся из трех учебных расписаний в `SLOT_SCHEDULES`; набор зависит от выбранной даты. Просматриваемый месяц хранится отдельно от выбранного дня, поэтому при листании выбор сохраняется. `buildCalendarGrid(year, month)` возвращает массив недель с объектами `Date`, начиная с понедельника; месяц имеет индекс от 0 до 11. После каждой вставки через `innerHTML` обработчики назначаются новым кнопкам.

## Проверка вручную

1. Откройте страницу: сегодня выделено, шесть слотов видны, «Далее» отключена.
2. Выберите время: проверьте подсветку, нижнюю панель и окно «Далее».
3. Выберите другой день: время сброшено, расписание обновилось, «Далее» отключена.
4. Перелистайте несколько месяцев туда и обратно, включая декабрь и январь. Выберите день после перерисовки.
5. Вернитесь в прошлый месяц: дни приглушены, клики и клавиатура не позволяют их выбрать.

Папки `frontend-2-lesson` и `frontend-2-complete` отсутствовали в исходном проекте; функции написаны самостоятельно.
